# 00. 项目总纲

## 1. 项目定位

镜中边城是一个 AI 驱动的持续运行小镇模拟器。它不是传统关卡制游戏，也不是多人房间游戏。第一阶段的目标是做出一个“自己活着”的小村落。

项目核心体验：

```text
玩家打开网页，不是进入一个从零开始的副本，
而是看见一个已经在运行的小村落。
NPC 有自己的家、工作、钱、物品、关系、记忆和日常目标。
村庄会因为他们的行动慢慢变化。
```

## 2. 世界背景

### 时代基调

- 参考中国三国时期。
- 地点气质参考江南水乡与农耕村落。
- 当前村落远离主战场，但能感受到时代阴影。
- 当前核心不是战争，而是生活、生产、关系和村庄经营。

### 第一阶段主题

```text
乱世边缘中的小村生活
```

表现重点：

- 种田、捕鱼、养马、修屋、做工。
- 家庭布置、院落装饰、村中关系。
- 工作岗位、工钱、物资交换。
- 村民日常、记忆、目标和心情。
- 江南水乡的视觉气质。

### 远期主题

远期可以加入：

- 村庄围栏。
- 木寨、寨门、瞭望台。
- 守夜、巡逻、民兵。
- 外来盗匪/敌对 AI。
- 防御战斗。
- 村落逐步坞堡化。

但这些只进入远期规划，第一阶段只预留接口。

## 5. 核心架构原则

### 原则 1：小镇只运行一份

很多人打开网页时，不能为每个浏览者启动一份模拟。所有浏览者都订阅同一个 WorldRuntime。

```text
一个 WorldRuntime
多个 Viewer
```

### 原则 2：浏览者不是玩家实体

第一阶段的网页浏览者只是旁观者：

- 不进入 NPC 感知范围。
- 不触发 LLM。
- 不改变世界状态。
- 不参与路径、对话、工作和经济系统。

### 原则 3：LLM 不能直接改世界

LLM 只能提出意图或计划。世界状态只能由 Game Server 的规则引擎和 ActionExecutor 改变。

错误：

```json
{ "setMoney": 999, "placeBedAt": [10, 20] }
```

正确：

```json
{
  "intent": "improve_home_comfort",
  "preferred_object_tags": ["bed", "comfort"],
  "reason": "最近睡不好"
}
```

再由系统检查材料、槽位、权限、碰撞、路径后执行。

### 原则 4：地图不是背景，是世界状态

地图由两部分组成：

```text
静态地形底板：河流、道路、地形、主要建筑结构
动态对象层：床、花、农作物、马槽、马、木桶、工具、家具
```

AI 不能随意改静态底板，但可以在规则允许的槽位里放置、建造、种植、养殖和装饰。

### 原则 5：所有内容尽量表驱动

应通过表或配置扩展：

- 动作。
- 动作阶段。
- 事件类型。
- 动画能力。
- 对象模板。
- 交互点。
- 岗位。
- 工作任务。
- 物品价格。

这样后续加入“钓鱼、坐下、甩杆、喂马、刷马、种花、修墙、守夜”都不需要大改代码。

## 6. MVP 验收标准

第一阶段 MVP 结束时应该能看到：

```text
网页打开后显示一个江南三国风小村落。
5-10 个 NPC 会持续生活。
NPC 有工作、钱、物品、目标。
NPC 能种田、捕鱼、养马、做工。
NPC 能买床、摆花、改善家。
地图对象会变化。
动作缺少动画时会显示头顶图标。
很多人同时打开网页时，只是共同观看同一个小镇。
LLM 挂了，小镇仍可通过行为树低频运行。
```
