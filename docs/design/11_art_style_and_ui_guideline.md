# 11. 美术风格与 UI 规范

## 1. 题材基准

```text
中国三国时期背景
江南小村落
远离战火
生活、生产、经营、关系为核心
非宫廷、非武侠、非玄幻、非西式奇幻
```

一句话：

```text
乱世边缘，一处仍在努力过日子的江南村落。
```

## 3. 色彩方向

主色：

```text
土黄
木褐
灰瓦
竹青
稻黄
水绿
麻布灰
```

点缀：

```text
暗红
靛青
暖黄灯火
旧纸色
```

避免：

```text
高饱和霓虹色
现代科技蓝
欧美 fantasy 紫光
过重金属质感
```

## 7. UI 总原则

```text
视觉古意
交互现代
信息清楚
避免厚重宫廷感
避免玄幻网游感
```

## 8. UI 材质

建议使用：

```text
竹简
旧纸
布帛
木牌
漆木边框
淡水墨纹理
印章式角标
```

不要使用：

```text
玻璃拟态
赛博 HUD
欧美羊皮卷过度装饰
过多金边龙纹
```

## 10. 正式 UI 面板

### 顶部状态条

显示：

```text
游戏日
时辰
季节
天气
观看人数
```

### 人物面板

```text
姓名
年龄
住处
职业
钱袋
心境
当前目标
关系摘要
```

### 村中记事

显示公开事件：

```text
阿衡在马棚喂马，得 3 钱。
林娘在家门前种下花。
南田的小麦成熟了。
```

### 工作面板

```text
岗位
雇主
地点
工钱
未完成任务
```

### 对象信息面板

点击床、花、马、作物等对象显示：

```text
名称
所属者
状态
可交互动作
相关事件
```

## 11. 头顶图标风格

图标用于动作缺失时的表现，也用于快速表达状态。

要求：

```text
手绘感
低饱和
清晰识别
和古风 UI 一致
```

第一批图标：

```text
睡觉
吃饭
喝水
钓鱼
种田
浇水
喂马
刷马
做木工
搬运
说话
思考
赚钱
生病
开心/低落
```

## 12. 战斗远期视觉预留

现在不做战斗，但可预留：

```text
木栅栏
村门
瞭望台
警钟
火把
民兵训练场
武器架
```

这些第一阶段可以作为不可用装饰或隐藏内容，不进入核心玩法。

## 13. 风格红线

```text
不要现代家具
不要欧式城堡
不要魔法阵
不要现代货币符号
不要钢铁盔甲泛滥
不要一开始就军营化
不要把江南村做成北方边塞
```
